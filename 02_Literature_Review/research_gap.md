# Research Gap Analysis

## Identified Gap

The literature reviewed in Assignment 1 identifies repeated limitations in existing information-security risk assessment approaches:

1. Manual assessment processes.
2. Dependence on expert judgement.
3. Subjective or inconsistent scoring.
4. Dependence on predefined risk values.
5. Limited automation and practical tool support.
6. Limited practical testing.

## Proposed Response

CRAT addresses this gap by providing a small Python prototype that applies a defined likelihood-impact scoring process consistently.

## Gap-to-Solution Mapping

| Literature Gap | CRAT Response |
|---|---|
| Manual scoring | Automatic score calculation |
| Subjective classification | Defined score thresholds |
| Difficult prioritization | Automatic ranking of multiple risks |
| Limited practical tools | Simple Python prototype |
| Limited practical testing | Synthetic scenarios and manual 5×5 baseline |

## Scope Boundary

CRAT is not presented as a replacement for enterprise risk management. It is an academic prototype designed to demonstrate a measurable and structured risk-assessment process.
