# CRAT Preliminary Prototype

## Requirements

- Python 3.10 or newer is recommended.
- No external Python packages are required.

## Run the prototype

From this folder:

```bash
python crat.py
```

## Run automated tests

```bash
python -m unittest test_crat.py
```

## Run the manual baseline

```bash
python manual_baseline.py
```

The prototype is intentionally simple because the research proposes a preliminary academic prototype rather than a complete enterprise security system.
